# Avviso sui dati ATMA

I dati statici di fermate e associazioni fermata-linea contenuti in questa cartella sono stati estratti dal dataset NeTEx `IT-ITI3-ATMA_L1`, pubblicato tramite il National Access Point italiano e attribuito a Regione Marche / RAP Marche – ATMA.

Il file sorgente non contiene un campo o una dichiarazione esplicita di licenza. La scheda pubblica NAP consultata descrive il dataset e le categorie di dati, ma non mostra una licenza di riutilizzo. Di conseguenza, questo pacchetto è predisposto per test e verifica tecnica: **non pubblicare i file derivati su un repository pubblico finché le condizioni di riutilizzo non sono state confermate**.

La selezione geografica è un rettangolo attorno ad Ancona, non il confine comunale ufficiale.
